# Sci-Station

读论文、记笔记、开 AI 圆桌的本地科研工作台。

> 当前版本：0.2.0
>
> 开发预览版 · Apple Silicon Mac · macOS 15 或更新版本

[已发布版本](https://github.com/Funyday-k/Sci-Station/releases) · [中文教程](docs/TUTORIAL.zh-CN.md) · [English](docs/README.en.md)

## 从源码运行

安装 Go 1.26 和 Xcode Command Line Tools 后，在仓库根目录执行

```sh
make run
```
