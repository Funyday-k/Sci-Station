## Accepted architecture changes

- **Swift and Python runtime machinery.** Swift Loop versus sidecar selection, sidecar discovery, Python isolation flags, JSONL handshake versions, LangGraph transport, Swift event-envelope coding and package-path assertions belong to the retired runtime. ADR-0004 selects one desktop host. Caller-visible timeout/failure, source integrity, cancellation and approval behavior remain covered by the workflow rows.
- **File editing.** The selected local CLI owns editing and applies its own configured permission policy. A decision applies only to the originating live request. An old Swift checkpoint that resumed a native tool write after process restart has a different lifecycle from that decision. Approved domain notes and tasks retain persistent, revision-checked receipts in the research repository.
- **Storage and grants.** The workstation starts in a fresh, explicitly selected root. Old bookmark, Swift YAML/JSON, event/checkpoint and graph SQLite/JSONL migrations are useful historical fixtures. The new app leaves those stores untouched. Test unsupported input, preserved user bytes, all-or-nothing publication and source-preserving index recovery using the active formats. External directory grants require fresh authorization on restore. The ADR records hardened runtime and app-managed grants, including separate OS permissions for calendars and reminders.
- **Host-specific tests and placeholders.** SwiftUI view identity, observation invalidation internals, AX-probe process wire format, debug-only Unix socket protocol, Swift lint budgets and the Python UI harness do not define the new implementation. Reachable menus, keyboard focus, native selection, navigation, editing and quit remain observable. The historical Code, Data, Experiments, Writing and Theory tabs were placeholders. Actual code/data/figure access and editor/Python actions belong to Materials.

## Observations and release evidence

- **Brand provenance.** The prototype at `ba1a6bf4889d2922251d23f04fee3d68870fdf56` and the promoted repository have identical Git blobs for the [app icon](../../packaging/macos/roundtable.icns) (`41b407a959fb64f806f0e6216d35391470ed8739`) and [shell mark](../../web/static/roundtable-mark.png) (`5e80c82c80959bff780a768aecb15f850a3d6c80`). The [bundle verification](../../packaging/macos/verify.sh) compares the installed icon bytes with the source; the [shared shell](../../web/static/workspace-shell.html) uses the verified mark.
- **Launch appearance.** The released Swift [view](https://github.com/Funyday-k/Sci-Station/blob/5fa221683aef9750ba308d024227354f7ac07a8a/Sci-Station/UI/LaunchAnimationView.swift) and coordinator at v0.2.0 are unchanged at the comparison baseline. An isolated AppKit comparison on macOS 27.2.1 compiled that view and the [candidate view](../../internal/desktop/native_launch_darwin.m) together. At 620 × 360 in Dark Aqua all 27 recorded animation settings matched for initial/final values, easing, and timing rounded to 0.01 s. With a fixed neutral backdrop the decorative layers and titles had zero differing RGB pixels at both endpoints (223,200 pixels each). The native readiness fixture passed. Desktop-composited glass, intermediate captured frames and historical-vs-current installed launches on macOS 15 are outside this measurement.
- **Prototype data.** The actual pre-cutover snapshot manifest contained ten directories and zero ordinary files. An isolated restored copy reopened. A separate populated recovery drill used two projects sharing a PDF, two meeting IDs, notes, an annotation and source links on page 2. The packaged service read the PDF bytes/text and the stored locators; restored external project grants required reauthorization. Preserve that distinction when reporting the result.
- **Historical overwrite and recovery.** A copy of the installed original Swift 0.2.0 build 2 was packaged locally as ZIP and DMG, verified with its original signature and whole-file manifest, replaced in a disposable Applications folder with the earlier Go candidate, then restored. The locally created archives exercise a historical app bundle. Both restored copies had Swift executable SHA-256 `1e38fafcb817fb9f72432669a2ea8ff9d193e6c7a54ca1b6a7f839967e85943f`. Both replacement Go executables had SHA-256 `b707b9d8703e604aa4ba0df83b7feb03bb494b4217f3d8288ba473df5bddc6d0`. The earlier Go process wrote an isolated task and exited cleanly. The drill checked the legacy and candidate fixture bytes through rollback. The macOS 15 CI job uses two Go build numbers from the same source. Its [install script](../../Tools/scripts/test-release-install.sh) drives the [headless data check](../../tests/package-install-smoke.py) and [installed native navigation test](../../tests/installed-app-ui/InstalledAppUITests.swift). The hosted result for a particular PR revision belongs to its workflow run. The local observations here cover bundle replacement and fixture integrity. First-launch Keychain, Calendar and Reminders consent need separate OS observations.
- **Coverage denominator.** The [Swift Testing suites](https://github.com/Funyday-k/Sci-Station/tree/8124e7ab728e37415fb054d5344dc5029005262d/Tests/SciStationCoreTests), [legacy runner registrations](https://github.com/Funyday-k/Sci-Station/tree/8124e7ab728e37415fb054d5344dc5029005262d/Tools/SciStationCoreTestRunner/Suites), [native navigation XCTest](https://github.com/Funyday-k/Sci-Station/tree/8124e7ab728e37415fb054d5344dc5029005262d/Tools/SciStationUISmokeTests) and [Python test declarations](https://github.com/Funyday-k/Sci-Station/tree/8124e7ab728e37415fb054d5344dc5029005262d/AgentRuntime/tests) contain 115, 323, 1 and 74 declarations respectively (513 total). Parameterization and multi-assertion tests make this unsuitable as a passing-test count. Match a concrete old assertion to its replacement before closing a difference. Visible behavior within a retired transport suite remains in scope.
