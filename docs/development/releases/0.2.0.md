## Release goal

`0.2.0` is a beta that consolidates the documentation reset and version-management foundation, the Phase 0 performance/design-system foundations, and a round of AI Lab + PDF reader UI/UX improvements. The larger version number reflects the breadth of change since `0.1.0`.

## Scope

### Added

- New `docs/development/` information architecture.
- Versioning policy, release process and packaging guide.
- AI-assisted development process.
- Gitignored user feedback intake process for user requests, bugs and feature ideas.
- Proposal/release/changelog/manual test templates.
- Design-system foundations: extended `SciStationDesignTokens` and a reusable component kit (`SciBadge`, `SciSectionCard`, `SciEmptyState`, `SciActionButton`).
- AI Lab selection workflow: `询问 AI` / `Ask AI` quick action that sends the current PDF text selection to the assistant, plus localized Summarize and Todo-draft selection actions.
- `0.2.0` Proposal and release record.

### Changed

- Development documentation no longer uses historical linear Proposal taskbooks as the primary source; knowledge is organized by module and release process.
- Raw user feedback is separated from AI-maintained development docs.
- AI Lab: localized assistant mode labels to `询问` / `助理` (`ask` / `agent`), constrained the reasoning box width, and removed tool-call row timestamps.
- PDF reader right rail: made the drag-to-resize handle visible.
- Performance foundations: extracted `TodoQueries` and `AgentStreamStore` to reduce app-wide view invalidation.

### Fixed

- Missing release management structure for the beta line.
- The AI assistant can now read user-selected PDF text through the selection action bar.

## Compatibility

- No user data schema change intended.
- No Research Root migration intended.
- No Agent protocol change intended.
- Code changes are limited to UI/UX and internal refactors; no user data, schema or Agent protocol changes.
