# Releases

本目录记录每个版本的发布范围、验证、已知问题和最终产物。

## 文件命名

```text
<version>.md
```

示例：

```text
0.1.1.md
```

## 每个 release record 必须包含

- Version / Build / Branch / Tag / Commit。
- Scope。
- Compatibility。
- Validation。
- Changelog summary。
- Known issues。
- Final decision。
