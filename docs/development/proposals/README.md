# Proposals

本目录只保存当前和未来版本的可执行 Proposal。旧的历史任务书不再保留在开发入口中。

## 使用规则

- 每个版本最多一个主 Proposal。
- Proposal 必须能直接交给 AI 执行。
- Proposal 完成后，将长期有效信息沉淀到 `modules/`、`testing/`、`versioning/` 和 `releases/`。
- 完成的 Proposal 可以保留作为该版本执行记录，但不再作为长期架构说明。
