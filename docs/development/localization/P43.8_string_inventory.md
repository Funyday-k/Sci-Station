# P43.8 String Inventory

更新时间：2026-05-11

## Scope

P43.8 本轮采用 Swift `L10nKey` registry。目标是先建立可测试、可审计的 key 体系，并迁移 Shell / Toolbar / Project lifecycle / Settings 的高频入口；其余大面积硬编码文案登记为 deferred，避免与 P43.9 UI polish 产生过大的交叉 diff。

## Status Legend

| 状态 | 含义 |
|---|---|
| migrated | 已接入 `L10nKey` / `appModel.t(...)` / `ToolbarPolicy.resolve(..., language:)` |
| partial | 已迁移主要入口，仍有次级文案或深层表单待迁移 |
| deferred | 保留到 P43.9 或后续专门本地化迭代 |
| user-content | 用户数据、文件名、论文标题、项目标题，不翻译 |
| code-symbol | tool name、system image、file extension、debug event、路径片段，不翻译 |

## Audit Allowlist

允许保留英文或符号类字符串：

1. SF Symbol 名称，例如 `folder`、`sparkles`、`sidebar.right`。
2. Tool / MCP / agent runtime 名称，例如 `write_markdown_plan`、`Swift Loop`、`LangGraph Sidecar`。
3. 文件扩展名、路径、YAML key、debug event 名称。
4. 用户内容：项目名、论文题名、作者、标签、文件名、Markdown 正文。
5. 品牌或协议名：PDF、DOI、arXiv、MinerU、OpenAI-compatible。

## Follow-Up

1. P43.9 UI bug bash 时优先迁移 PDF / Wiki / Markdown editor 中 P43.7 新增文案，并检查中文长度。
2. Library import dialogs 与 metadata inspector 应进入下一轮 localized form pass。
3. AI Lab permission review 需要和安全 preset 文案一起迁移，避免只翻译按钮而遗漏风险说明。
