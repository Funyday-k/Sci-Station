# Sci-Station Built-In AI Presets

This directory contains Sci-Station product AI configuration that is intended to be versioned.

These files describe curated defaults for the in-app Agent Platform:

- agent profiles and subagents
- slash command templates
- skills and reference material
- lifecycle hooks
- permission and safety rules
- MCP server configuration templates

All sensitive values must be represented as references, not raw values. Runtime secrets belong in Keychain or another secure store.
