# Changelog

## [Unreleased]

- The desktop welcome window includes a named workspace creation wizard, two templates, and an optional sample workspace. A workspace folder can be renamed in place, and its recent-workspace entry can be cleared.
- Project settings include color and system symbol presets, custom values, and a live preview. The saved appearance is shown in the sidebar, project list, and overview.

### Fixed

- The macOS workspace closes with the red window button or Command-W after the launch animation. Quitting the app cancels active model requests and saves the meeting's interrupted state.
