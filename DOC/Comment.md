# 多项目管理功能

## UI修改建议

左边侧栏需要做成多项目堆叠的形式，我可以单击来切换不同的项目，并且右键可以编辑项目本身的信息，同时也可以加上折叠栏，可以收放单个项目下的不同栏目


## TODO 功能优化

由于对于需要做多项目的人，会有来自不同项目的任务，因此需要将todo加上来自于不同项目的标签进行分类，因此Tasks栏目对于每一个项目只显示带有本项目标签的todo，同时还要添加一个总的能查看来自所有项目的todo列表，这个东西放到Home页面中，放到日历下边，同时稍微缩小日历的高度。

同时，对于home页面的工作区管理内容需要优化，现在无法在两个工作区来回切换的时候查看总共的两个工作区，而是只能看到当前打开的工作区，同时下方的工作区信息和上边的工作区管理合并，可以显示成每一个工作区是一个小方块，显示其基本信息的形式。

## 工作区优化

由于论文库需要全局使用，也就是对于不同的工作区都要可以看到，只是我们可以对每一个论文增加标签，说明这个文章对于某个工作区是可以用到的，那么对于一个工作区内部的wiki以及其他知识库都要基于选择好的论文进行构建，所以我们指定一个全局的最基本的路径，然后在这个路径下创建不同的项目，这样我们的agent的设置之类的都可以全局使用
